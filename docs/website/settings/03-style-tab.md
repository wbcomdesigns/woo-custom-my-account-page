# Style Tab

The Style tab lets you override six colors. By default the account menu follows your theme's colors, so you only set what you want to change.

## Change a color

1. Go to **WB Plugins > Woo My Account > Style**.
2. Pick a color in the field you want to change.
3. Click **Save Changes**.
4. Open the My Account page and check the result.

## Options

| Option | Default value | What it does |
|--------|---------------|--------------|
| Menu item colour | `#777777` | Color of the menu items. |
| Menu item hover colour | `#000000` | Color of a menu item when the pointer is over it. |
| Log out text colour | `#ffffff` | Text color of the Log out item. |
| Log out hover text colour | `#ffffff` | Text color of the Log out item on hover. |
| Log out background | `#c0c0c0` | Background color of the Log out item. |
| Log out hover background | `#333333` | Background color of the Log out item on hover. |

## Only changed colors apply

The plugin applies a color only when it differs from the default value shown above. If you leave a field at its default, the menu keeps following your theme.

To set a color that matches a default value exactly, pick a color that is slightly different. The default value itself has no effect.

## Where the colors apply

- The menu item colors apply to the account menu.
- The four Log out colors apply to the Log out item only.

## Other styling

- To style a single item, add a CSS class on the item and write the CSS in your theme. See [Icons and CSS classes](../manage-the-account-menu/08-icons-and-css-classes.md).
- The menu stylesheet includes a right-to-left version, which WordPress loads for RTL languages.
