# Overview Tab

The Overview tab at **WB Plugins > Woo My Account** shows what the plugin is doing on your store. It has no settings to save.

## Portal status

| Item | What it tells you |
|------|-------------------|
| My Account page | **Classic shortcode** if the WooCommerce My Account page contains the `[woocommerce_my_account]` shortcode. **Block based** if it does not. **Not set** if no My Account page is assigned in WooCommerce. |
| Menu entries | The number of entries in the My Account menu, how many are custom, and how many are role-restricted. |
| Default endpoint | The slug of the page customers land on when they open My Account. |
| Updates | Shows **Active**. Automatic updates need no setup. |

The **Manage endpoints** button opens the Endpoints tab.

## Menu entries count

The count covers top-level entries. Items placed inside a group are not added to the total.

## Support and resources

The tab links to the documentation, the support center and a feedback form.
